# HIROO Coffee & Kitchen

Premium one-page landing website for HIROO — a Japanese-inspired specialty coffee shop and brunch destination in Ashgabat, Turkmenistan.

## Live Demo

[View Live Site](https://your-domain.com)

## Overview

A fully responsive, multilingual landing page built with vanilla HTML, CSS, and JavaScript. The design follows Wabi-Sabi philosophy — finding beauty in imperfection, simplicity, and natural materials.

## Features

- **Hero section** with fullscreen video background and animated glowing logo
- **About section** with split layout and image gallery
- **Menu experience** with tabbed navigation (Coffee, Signature Drinks, Breakfast, Desserts)
- **Signature experience** cards with glassmorphism effects
- **Photo gallery** with masonry grid layout
- **Location section** with embedded Google Maps and contact info
- **Reservation form** with date/time picker and validation
- **Multi-language support** — Turkmen, Russian, English
- **Smooth scroll animations** via Intersection Observer
- **Fully responsive** — desktop, tablet, mobile
- **Mobile hamburger menu** with slide transition

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, grid, flexbox, glassmorphism, keyframe animations
- **JavaScript (ES6+)** — vanilla, no frameworks
- **Google Fonts** — Outfit + Playfair Display
- **Font Awesome 6** — icons
